# Примеры страниц (референс, не часть сборки)

Здесь лежат страницы из первого прохода прототипа — они больше не подключены к роутингу
в `src/App.tsx` и не попадают в сборку (вне `tsconfig.app.json` → `include: ["src"]`).
Оставлены как референс паттернов вёрстки поверх дизайн-системы из `src/components`.

- `pages/Dashboard.tsx` — дашборд с карточками метрик и таблицей топ-объектов
- `pages/Objects.tsx` — список объектов с поиском/фильтрами (сетка карточек)
- `pages/ObjectDetail.tsx` — детальная карточка объекта (левая колонка с CTA + правая с описанием)
- `pages/Statistics.tsx` — древовидная таблица с фильтрами
- `pages/Placeholder.tsx` — универсальная заглушка для ещё не реализованных разделов
- `data/*.ts` — демо-данные, которые эти страницы использовали

## Как использовать

Копируйте нужный файл (или фрагмент) в `src/pages/`, поправьте импорты на
`../components/...` и `../lib/...` (в примерах они на уровень глубже — `../../src/...`,
из-за расположения вне `src/`), подключите роут в `src/App.tsx`.

Дизайн-система (шрифт Yandex Sans Text, цвета, логотип, лобстер-маскот, сайдбар,
UI-компоненты — Button, Card, Badge, Input, Select, SearchInput, TreeTable) живёт
в `src/components` и `src/index.css` и продолжает работать независимо от этих примеров.
