# Roadmap — Malllist (TC Catalog)

**Связанный мастер-план:** docs/2026-10-full-system-audit-roadmap.md

## Цели
- Красивый, быстрый каталог ТЦ
- Зелёная зона PageSpeed (особенно LCP, CLS, TBT на главной и в карточках)
- Без морганий, перекрытий, самопроизвольного скролла

## Известные проблемы (на момент 2026-10-14, обновлено по ходу)
- Моргание картинок при загрузке (3+ фазы) — сильно смягчено Task 001 (OptimizedImage) + Task 002 (lower idles)
- Сложный скролл полок — починили ранее (CSS snap + simplified JS), задокументировано
- Возможные перекрытия на home — negative margins задокументированы, не баги
- Snapshot vs React разница — в процессе (main + TcBrowseBodyMount)

## План (по приоритету)

1. Системные улучшения (Image, motion, snapshot) — **в процессе / advanced**
2. Стабилизация домашней страницы (hero + glance + shelves) — **начато**
3. Улучшение карточек ТЦ
4. PageSpeed конкретно malllist
5. Финальная полировка

**Статус 2026-10-14:** Task 001/002 активно, много миграций и timing tweaks. Продолжаем по мастер-плану.
