(ищи, где мапится `tenantsAt`):

```ts

// Ключ есть, массив пустой — у ТЦ нет фактов, достойных блока.
```

## 1. «Интересные факты» (секция `id="facts"`)

Если у ТЦ `retailInfo.factCards` не null — вместо текущего списка highlights
новый компонент `TradeCenterFactCards`:
- пустой массив → блок и пункт оглавления не выводятся;
- одна белая карточка, строки в две колонки (на телефоне одна), разделители
  между строками; в строке крупный жирный `headline` (~18px, на телефоне 16px) и
  под ним `text` мелко серым;
- сразу 6, остальные под кнопкой «Ещё N фактов» (правильное склонение:
  факт/факта/фактов), раскрывает на месте; ничего не раскрывается по клику на
  сам факт.
Если factCards === null (ключа нет) — всё как сейчас.

## 2. «Что говорят посетители» (секция отзывов `id="reviews"`)

Если у ТЦ есть `retailInfo.reviewThemes` и `reviews >= 100` — вместо ленты
дословных отзывов Яндекса новый компонент `TradeCenterReviewThemes`:
- заголовок «Что говорят посетители» (иконка MessageSquare);
- карточка рейтинга: крупно оценка (из того же источника, что сейчас рейтинг
  Яндекса на странице — найди, откуда берётся рейтинг/число отзывов в hero или
  в текущем блоке отзывов; если оценки нет — карточку рейтинга не выводить),
  звёзды, «по N отзывам в Яндекс Картах» (общее число отзывов, если известно,
  иначе reviews), ссылка «Все отзывы на Яндекс Картах ↗», если ссылка на
  карточку Яндекса уже есть в данных страницы;
- две колонки «Хвалят» (зелёная точка/полоски #2f8f4e) и «Жалуются» (терракота
  #b4533a): тема слева, «N% отзывов» справа (у первой строки «отзывов», дальше
  просто «N%»), полоска под ней шириной share/max(share в обеих колонках)*100%;
- колонка без тем не выводится; обе пустые — блок не выводится вовсе;
- никаких цитат, имён, дат, «Коротко», подписи про методику.
Дословные отзывы у таких ТЦ не показывать вообще (владелец опасается нарушить
правила Яндекса). Без reviewThemes — всё как сейчас.

FAQ/JSON-LD: если в FAQ страницы ТЦ есть вопросы, построенные на дословных
отзывах, у ТЦ с reviewThemes замени их одним вопросом «Что посетители говорят о
{name}?» с ответом из топ-3 «хвалят» и топ-2 «жалуются» с процентами.
