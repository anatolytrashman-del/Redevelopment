# Задание: соседние и похожие БЦ на карточке бизнес-центра

Карточка БЦ. План: `BCMINSK_SEO_PLAN.md`, раздел «Карточка БЦ — приоритет 2», два
соседних пункта:

1. Сравнение с ближайшими БЦ — таблица на 3–5 объектов того же района и класса.
2. Похожие БЦ — 4–6 карточек, подбор по классу и району.

В плане они стоят отдельными пунктами намеренно: это две разные подборки с разной
задачей (таблица для сравнения цифр, карточки для перехода дальше по сайту).
Не делай их одним блоком и не показывай в обоих одно и то же.

## Ловушка, на которой здесь уже теряли данные

**PostgREST в этом проекте отдаёт максимум 1000 строк.** Если для подбора берёшь
каталог целиком, выборка обязана быть постраничной через `.range()` — иначе хвост
каталога пропадёт МОЛЧА, без всякой ошибки, и подбор станет неполным на части
объектов. Так уже терялись 141 карточка поставщика и 393 снимка сайтов.
Запросы делай через соответствующий `src/lib/*Api.ts` и оборачивай в `withRetry`.

## Готово, когда

`npm run build:app` чистый; на карточке есть обе подборки, они не дублируют друг друга;
у объекта без подходящих соседей блок не показывается вовсе, а не висит пустым.

## Общие правила (обязательны)

Репозиторий: `anatolytrashman-del/Redevelopment`. Перед началом прочитай `AGENTS.md`
в корне — там правила проекта и грабли, на которые здесь уже наступали.

- Ветку бери от `claude/redevelopment-platform-prototype-oodobu` (это прод-ветка,
  НЕ `main`), имя своей ветки — с префиксом `codex/`.
- Проверка перед PR: `npm ci && npm run build:app`. **Никогда не запускай
  `npm run build`** — он уходит в полный пререндер на двадцать минут.
- `git add` только изменённые файлы поимённо, никогда `git add -A`.
- PR открывай в `claude/redevelopment-platform-prototype-oodobu`, описание по-русски.
  **PR не мержи** — принимает и мержит другая сторона.
- Миграции в базу не применяй: если нужна схема, положи SQL-файл в
  `supabase/migrations/YYYYMMDD-<тема>.sql`, закончи его строкой
  `NOTIFY pgrst, 'reload schema';` и упомяни файл в описании PR.
- Секретов и сети у тебя нет: в Supabase, Resend, Vercel, Google и Telegram не ходи.
