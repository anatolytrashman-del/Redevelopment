## Что сделать

Вместо блока «Посетителю» — ДВА блока. «Режим работы», «Правила посещения» и
всё, что было бы «Полезно знать» (гардероб, курение, инфоцентр, праздничный график),
на странице больше не выводятся: основные часы уже на первом экране.
Данные в базе не трогать.

### 1. «Как добраться и где встать» (id 'getting-here', пункт оглавления «Как добраться»)

Две колонки на десктопе, одна на мобилке.

- **Транспорт** (белая карточка). Строки «подпись — значение»:
  - Метро: цветная точка линии + станции с расстояниями одной строкой («Немига» 450 м ·
    «Фрунзенская» 600 м). Брать из записи `mode: 'metro'`; если там текст, вытащить
    пары «станция — N м».
  - Автобус, Троллейбус, Маршрутка, Трамвай: номера маршрутов маленькими плашками.
    Номера вытащить из текста записи регуляркой (цифры с необязательной буквой: 119с,
    40а, 300Э). Названия остановок не выводить. Несколько записей одного вида
    объединить, дубли номеров убрать.
  - Запись про аэропорт или вокзал (текст содержит «аэропорт» или «вокзал») —
    отдельной строкой «Из аэропорта» / «С вокзала», текст сокращать до первого
    предложения.
  - «На машине» и «Пешком» не выводить: въезд уже есть у парковки.
- **Парковка** (белая карточка). Подпись: «Парковка · въезд с …» (из item с «въезд»).
  Три плитки: число мест (+ «круглосуточно», если в hours есть паркинг круглосуточно
  или в summary), цена за первые часы, цена каждого следующего часа. Брать из
  `parking.items` по подписям (регулярки «мест», «перв», «следующ»). Нет значения —
  плитки нет. Ниже «Как встать бесплатно» — items, чья подпись начинается с
  «Бесплатно» или про «Электромобили», списком с зелёной галочкой, текстом коротко
  («3 часа по купону за покупку в «Гиппо» от 20 руб.»: подпись + значение, без
  скобок). Одна мелкая приглушённая строка — электрозарядки (сократить до числа
  станций и уровня, если получается, иначе первое предложение). Уровни, абонементы,
  телефоны, длинный summary не выводить.

### 2. «Скидки и события» (id 'offers-events', пункт оглавления «Скидки и события»)

- **Программа лояльности** — тёмная карточка (стиль как табло этажей в блоке «Что
  где»): слева название, под ним короткая подпись, если в тексте есть «без
  белорусского номера». Справа до трёх фактов плитками, вытащить из текста: «N балл
  за …рубль» → «1 балл / за каждый рубль в чеке», «в течение N часов» → «72 часа /
  чтобы отсканировать чек», «меняют на …» → первые два пункта списка + «за баллы».
  Если разобрать не удалось — просто текст, обрезанный до ~160 символов по
  предложению. Несколько программ — по карточке на каждую.
- **События** — карточки сеткой по 3 (на мобилке по одной): красная надпись «когда»
  (поле `date`, коротко, с заглавной), жирное название, «Подробнее ▾» раскрывает
  `text`. Первая карточка раскрыта. Порядок: сначала регулярные (в date есть
  «каждую», «по субботам», «ежегодно», «регулярно», «сезон», «ежемесячно», «летом»),
  потом остальные. Разовые события с датой в прошлом (год меньше текущего и нет
  признаков регулярности) не выводить.

Нет данных для блока — блок не рисуется, пункта в оглавлении нет. FAQ страницы не
ломать: вопросы про часы работы, парковку и транспорт остаются в FAQ.
