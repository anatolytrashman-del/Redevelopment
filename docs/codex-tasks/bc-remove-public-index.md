# Задача 6 — убрать Индекс Redevelopment из публичной части

Источник: `docs/bc-catalog-master-plan.md`, раздел «Задача 6». Перед началом прочитай
`AGENTS.md` в корне.

## Зачем

Решение владельца: публичная оценка чужих зданий делает будущего клиента
проигравшим — те, кого мы оценим низко, наши будущие плательщики. Индекс остаётся
внутри админки как инструмент приоритизации, но на публичных страницах его быть не
должно: ни балла, ни места в ряду, ни сортировки по нему, ни методики.

## Что сделать

**Сам расчёт `src/lib/businessCenterIndex.ts` НЕ удалять** и тесты
`src/lib/businessCenterIndex.test.ts` не трогать — расчёт остаётся для админки.
Убирается только публичный показ. Начни с `grep -rn businessCenterIndex src/` и
`grep -rn indexBySlug src/`, чтобы увидеть всю картину.

`src/pages/BusinessCenterDetailPage.tsx`:

  подпись в словаре разделов (~строка 130) убрать.

`src/components/businessCenters/BusinessCenterMarketBlocks.tsx`: компонент

### 2. Каталог

`src/pages/BusinessCentersMinskPage.tsx`:

### 3. Сортировка

`src/lib/businessCenterCatalogFilter.ts`: из типа сортировки убрать вариант
`'index'` (~строка 24), из списка подписей — `{ key: 'index', label: 'Индекс
Redevelopment' }` (~строка 37), из `sortCatalogCenters` — ветку `case 'index'`
(~строка 385).

Важно: сортировка по индексу сейчас, судя по всему, стоит сортировкой по умолчанию
или встречается в уже существующих ссылках. Разбор URL обязан пережить старое
значение `sort=index` — такая ссылка должна открывать каталог с обычной сортировкой,
а не падать и не показывать пустую выдачу. Сортировки по фактам (площадь, год,
класс, метро, алфавит) остаются как есть.

Ссылка на удалённую страницу не должна остаться висеть ни в разметке, ни в sitemap.

не надо, задача его не требует.

Публичных подборок «лучшие по индексу» быть не должно. Подборки на каталоге сейчас

индексу, — убери её; новых подборок придумывать не надо.
