# Задание: письмо-заказ поставщику, экранная часть (шаг 12, пункт 1)

Открой `docs/procurement-product-steps.md`, найди «Шаг 12 — письмо-заказ, сверка счёта,
плановый платёж». Из него нужен **только первый пункт**: письмо-заказ поставщику из
`purchase_orders` по шаблону `order`.

Два других пункта шага — сверка финального счёта и плановый платёж в `transactions` —
НЕ делать, они требуют живых данных.

Отправку письма тоже не подключай: ключей Resend у тебя нет. Доведи до состояния,
когда письмо собрано из заказа и показано в предпросмотре, а место фактической
отправки обозначено вызовом соответствующей функции API — её подключат отдельно.

## Готово, когда

`npm run build:app` чистый; из карточки заказа открывается предпросмотр письма с
подставленными позициями, реквизитами и условиями; шаблон `order` лежит там же, где
остальные шаблоны писем проекта, а не захардкожен в компоненте.
