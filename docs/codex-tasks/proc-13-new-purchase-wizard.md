# Задание: мастер «Новая закупка» и правка запроса (шаг 13, экранная часть)

Открой `docs/procurement-product-steps.md`, найди «Шаг 13 — мастер „Новая закупка“ и
автоподбор адресатов». Сделай из него ДВА пункта:

1. Мастер из трёх экранов — что нужно (раздел сметы / ведомость / свободный текст),
   кому шлём, что отправляем. Подробности в плане и в §2.1 документа, на который он
   ссылается.
2. Правка существующего запроса. Сейчас ветка `editingRequest` мертва: код есть,
   пути к нему нет. Она должна открывать тот же мастер с заполненными данными
   запроса — то есть форма создания и форма правки это один компонент, а не два.

**Третий пункт шага — автоподбор адресатов по снимкам сайтов — в это задание НЕ
входит.** Он требует живой базы и делается на другой стороне. Не трогай его.

## Готово, когда

`npm run build:app` чистый; новую закупку можно создать через мастер, существующую —
открыть на правку тем же мастером и сохранить без потери заполненных полей;
мёртвого кода от старой формы не осталось.

## Общие правила (обязательны)

Репозиторий: `anatolytrashman-del/Redevelopment`. Перед началом прочитай `AGENTS.md`
в корне — там правила проекта и грабли, на которые здесь уже наступали.

  **PR не мержи** — принимает и мержит другая сторона.

  `supabase/migrations/YYYYMMDD-<тема>.sql`, закончи его строкой
