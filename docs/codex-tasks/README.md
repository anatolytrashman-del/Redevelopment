# Готовые задания для Codex

По файлу на задачу. Каждый файл — самодостаточный текст: открыть, скопировать целиком
и вставить в Codex. Ничего дописывать не нужно.

Задания составляет Claude, запускает владелец вручную. Отметка о выдаче и приёмке —
в очереди `docs/codex-handoff.md`, разделение труда и правила приёмки там же,
правила для самого Codex — `AGENTS.md` в корне (Codex читает его сам).
