# Карточка ИИ-агента ChatGPT в разделе «Команда»

Правила репозитория — в `AGENTS.md` в корне, прочитай его первым делом. Ключевое:
ветка от `claude/redevelopment-platform-prototype-oodobu` (она же база для PR, не `main`),
перед PR чистый `npm run build:app` (**не** `npm run build` — он уходит в двадцатиминутный
пререндер), PR самому не мержить.

## Цель

На странице `/admin/contractors` («Команда») верхним блоком идут карточки ИИ-сотрудников.
Нужна новая карточка — **ChatGPT**, **сразу после Claude Code** (то есть вторая в списке):

- имя: `ChatGPT`
- role (подпись под именем): `ИИ-кодер`
- tag (бейдж справа от имени): `Pro`
- tasks: те же, что у Claude Code — «Разработка и правки платформы», «Публикация релизов на прод»
- иконка: знак OpenAI (см. п. 3)

## Файлы

1. **`src/data/aiAgents.ts`**, массив `aiAgents` — вставить объект вторым элементом
   (порядок массива и есть порядок карточек), `id: 'chatgpt'`.
   - `heartbeat` — как у `claude-code`:
     `{ staleAfterMinutes: 24 * 60, scheduled: false, cadence: 'по запросу' }`.
   - `staticActivity` **не задавать**. У Claude там `__BUILD_TIME__` (время сборки прода =
     «выпустил релиз»), для ChatGPT это была бы неправда: следа в базе у него нет, RPC
     `ai_agents_last_activity` ключа `chatgpt` не отдаёт. Карточка честно покажет
     «Ожидает задач» — см. `getAiAgentStatus` в `src/lib/aiAgentsApi.ts`, ветка `!iso`
     при `scheduled: false`. Фиктивное время не подставлять: смысл этого файла в том,
     что статус считается от реальной функции, а не рисуется константой.
   - Комментарий над объектом — по-русски, в стиле соседних записей, с датой и причиной:
     2026-09-17, владелец: «добавь ChatGPT сразу после Claude, бейдж Pro, тайтл ИИ-кодер,
     обязанности такие же, как у Клода».
2. **`src/data/aiAgents.ts`, тип `AiAgent`** — поле `icon` расширить до
   `'bot' | 'claude' | 'openai'`.
3. **Новый `src/components/contractors/OpenAiLogo.tsx`** — по образцу соседнего
   `ClaudeLogo.tsx`: inline-SVG, `viewBox="0 0 24 24"`, `currentColor`, `aria-hidden`,
   пропс `className`, без зависимостей. Тянуть SVG с CDN нельзя (прокси окружения
   закрывает jsdelivr), класть бинарник в `public/` ради одной иконки — лишнее.
   **Если не уверен, что воспроизведёшь фирменный узел OpenAI точно, — не выдумывай
   приблизительную форму.** Оставь `icon: 'bot'` (значок робота из lucide, уже поддержан)
   и напиши об этом в описании PR: кривой знак в админке хуже стандартного.
4. **`src/components/contractors/AiAgentCard.tsx`** — третья ветка в выборе аватара.
   У Claude кружок `bg-[#d97757]/15 text-[#d97757]` (терракота Anthropic) +
   `<ClaudeLogo className="h-5 w-5" />`; для OpenAI тот же шаблон с зелёным `#10a37f`.
   Бейдж `tag` уже рисуется для любого агента — его трогать не надо.
5. **`docs/session-journal.md`** — новая запись **сверху** (сразу после вводного абзаца),
   формат `- **YYYY-MM-DD** — ...`: что добавили, кто попросил и почему статус
   «Ожидает задач», а не «Онлайн». Файл большой, целиком не читай — посмотри `head -30`
   и вставь в начало списка.

## Чего делать НЕ надо

- Никаких SQL-миграций и изменений в Supabase: состав ИИ-агентов задаётся кодом,
  формы в админке для них нет намеренно.
- Не трогать `src/pages/Metrics.tsx` — там свой блок ИИ-кодера
  (`AI_CODER_NAME = 'Claude Code'`), он считает деплои по таблице `deployments`
  и к «Команде» отношения не имеет.
- Не `git add -A` / `git add .` — только изменённые файлы поимённо.

## Критерий готовности

Чистый `npm run build:app`; на `/admin/contractors` вторая карточка сверху — ChatGPT
с бейджем «Pro», подписью «ИИ-кодер», двумя задачами и статусом «Ожидает задач».
