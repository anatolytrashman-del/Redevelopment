# Задание: доверие к таблице сравнения КП (шаг 14)

Открой `docs/procurement-product-steps.md` и найди «Шаг 14 — доверие к таблице:
трассировка, рекомендация, режим lot». Выполни этот шаг целиком — в плане расписано,
что должно получиться.

Коротко, чтобы не потерять суть: сейчас таблица сравнения предложений поставщиков
показывает числа, но по ним нельзя понять, откуда они взялись и каким из них верить.
Нужно (1) клик по ячейке → предпросмотр счёта с подсветкой строки-источника,
(2) кнопка «Предложить отбор», которая берёт только позиции со статусом сопоставления
`exact` и учитывает срок поставки и доставку, (3) режим `lot` — чтобы отбор, лист
согласования, PDF и воронка работали так же, как в поштучном режиме.

Это фронтовая задача, живая база не нужна.

## Важное ограничение по UI

В этом проекте **вложенных модалок не бывает и быть не может**: у `Modal`
(`src/components/ui`) жёсткий `z-50` и свой обработчик Escape на каждую копию —
вторая модалка поверх первой ловит Escape вместе с первой, и закрываются обе.
Предпросмотр счёта поэтому показывай ВМЕСТО тела текущей модалки, с кнопкой «Назад».
Рабочий образец такого приёма — `src/components/suppliers/PurchaseDeliveries.tsx`.

## Готово, когда

`npm run build:app` чистый; из таблицы можно дойти до строки счёта, породившей число;
«Предложить отбор» не предлагает позиции, сопоставленные неточно; режим `lot`
доходит до PDF так же, как поштучный.
