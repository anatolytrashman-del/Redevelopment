## Вид

Заголовок и иконка Trophy как сейчас (графит). Две группы с мелкими лейблами:

1. **«Места в рейтингах»** — сетка 3 в ряд (2 на планшете, 1 на телефоне). Плитка:
   слева квадрат 58×58 — крупно «№{place}» и мелко «из {total}» (нет total — без
   второй строки). Если value вида «9 баллов из 10» и критерий про оценку —
   крупно «9/10», мелко «баллов». Квадрат тёмный (ink, текст белый), для place = 1 —
   золотой (фон #f6efdc, текст #b88a1e). Справа: короткий заголовок (жирный, до 2
   строк, line-clamp-2) и подпись «{кто} · {year}» серым.
   Порядок: сначала place = 1, потом по году убыванию.
2. **«Награды»** — сетка 4 в ряд (2 на телефоне). Плитка: крупно год, плашка с
   результатом, название премии (жирный, до 2 строк), номинация серым (до 2 строк).
   Порядок: по году убыванию. Плашка: winner/diploma/laureate/other — золотая,
   finalist/nominee — серая (фон icon-bg, текст icon).

Никаких абзацев `text`, `note`, источников, «subject», «recipient». Всё скрытое
раньше длинное пояснение не показывать вовсе (не раскрывать по клику).

## Короткие подписи (функции + тесты)

- `shortRankingTitle(entry)`: из headline (нет — из criterion+scope) убрать
  то, что уже в квадрате, и хвост про источник. Убирать в начале: «N-е место среди»,
  «N-й/N-е/N-я», «Первое/Второй/Третий … место в», «Первое место в топ-10»,
  порядковые слова «Первый/Второй/Третий» (если place это же число), «Один из
  двух/трёх … », «В десятке». Убирать в конце: «по опросу горожан», «по оценке
  Onliner», «: … знают NN% опрошенных минчан», «на 2021 год». Первая буква — заглавная.
  Ожидаемое (добавь в тест):
  - «8-е место среди крупнейших ТЦ Минска по арендопригодной площади» → «Крупнейших ТЦ Минска по арендопригодной площади»
  - «Самый посещаемый ТРЦ Минска по опросу горожан» → «Самый посещаемый ТРЦ Минска»
  - «Второй по посещаемости торговый центр Минска по опросу горожан» → «По посещаемости среди ТЦ Минска» (допустимо «По посещаемости торговый центр Минска» — главное без «Второй»; предпочтительно первое)
  - «Один из двух лучших паркингов у торговых центров Минска по оценке Onliner» → «Лучшие паркинги у торговых центров Минска»
  Если после чистки остаётся меньше 12 символов — вернуть исходный headline.
- `rankingSource(entry)`: «Опрос MASMI», если MASMI в scope/criterion/source/org;
  «Опрос горожан», если «опрос» без MASMI; «Onliner», если Onliner в headline/source;
  иначе критерий коротко: «по общей площади», «по арендной площади»
  (арендопригодная → арендная), с заглавной.
- `shortAwardTitle(award)`: title до « — », без года в конце (« 2021»), без
  «Медаль и диплом I степени» в начале (это уже на плашке) — для БСА получится
  «Республиканский конкурс на лучшее архитектурное произведение» (ок, клампится).
- `awardCategory(award)`: category; если начинается латиницей и в скобках есть
  русский — взять русский из скобок; «раздел «…»» → содержимое кавычек; если title
  содержит «— «X»», а category пустая — X.
- `awardPill(award)`: resultText с заглавной; для result = 'other' с длинным
  resultText (больше 20 символов) — «Награда»; для diploma с «медаль» — «Медаль I
  степени» (степень из текста).
