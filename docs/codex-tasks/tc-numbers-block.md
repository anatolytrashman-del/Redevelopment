## Группы (порядок показа)

Чистая функция `groupNumbers(entries)` в `src/lib/tradeCenterNumbers.ts`:

1. **«Масштаб»** — посещаемость и общий размер: label/text про «посещ», «посетител»,
   «весь комплекс», «общая площадь», «торговая площадь», «арендатор», «магазин».
   Не больше 2 цифр (остальные такие — в «Здание»).
2. **«Праздники в атриуме»** — text/label про «атриум», «Новый год», «новогод»,
   «инсталляц», «декорац», «ёлк», «весн» + украшения. Лента по 3 в ряд.
3. **«Здание»** — всё остальное, плитки по 5 в ряд (по 2 на мобилке).

Группа без цифр не выводится, заголовок группы — мелкий лейбл, как в макете. Если
всех цифр меньше 4 — без групп, просто плитки.

## Форматы

- **«Масштаб»**: большие белые карточки (2 в ряд), крупная цифра цветом text-ink (не красным — владелец убирает красный с иконок и цифр), одна
  строка-подпись. Под ней наглядность, если распознана:
  - *сравнение*: в text есть второе число со словом «жител»/«населен» или «больше,
    чем» + число с «млн/тыс.» → две полоски (наша цифра — графит #3b3d44 100%, вторая —
    серая пропорционально), подписи слева, значения справа. Название второй полоски
    — существительное рядом с числом («Жители Беларуси»);
  - *футбольные поля*: в text «N футбольных полей» (N от 1 до 40) → ряд из N
    маленьких зелёных прямоугольников-полей + подпись «≈ N футбольных полей» и
    остаток фразы после «полей» до точки, если он короткий.
  - иначе — просто цифра, подпись и первое предложение text мелко.
- **«Здание»**: плитка — иконка lucide по ключевым словам (экран/LED → Monitor,
  стекл/фасад → PanelsTopLeft или Grid2x2, строител/стройк → HardHat, паркинг/машин →
  Car, картинг/трасс → Flag, лифт/эскалатор → ArrowUpDown, этаж/высот → Building2,
  иначе → Sparkles), крупное значение, подпись одной строкой (label). Длинное
  пояснение (text) скрыто и раскрывается по нажатию на плитку (кнопка, aria-expanded;
  раскрытая плитка с красной рамкой, текст под пунктиром). По умолчанию все закрыты.
- **«Праздники в атриуме»**: тёмная лента, у каждой цифры сверху красная надпись
  «когда» из date (коротко: «Новый год 2025», «Весна 2025» — если date «декабрь 2024»
  и text про Новый год, писать «Новый год 2025»; иначе date с заглавной), крупное
  значение белым, подпись — label, одна-две строки.

Отдельные строки с датами и пометками «по данным ТЦ» под карточками убрать.
Подпись карточки (label) не длиннее ~60 символов — если длиннее, обрезать по слову.
