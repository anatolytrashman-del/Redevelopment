# Разбор отзывов ТЦ на темы (аналитика, без правки кода)

Владелец, 2026-09-25: разбор текста делает Codex (не ProxyAPI). Код репозитория
НЕ менять, ничего не коммитить. Только читать входные файлы и писать выходные.

Вход: `tmp/reviews-in/<slug>.txt` — до 600 свежих отзывов посетителей одного
торгового центра с Яндекс Карт, по строке на отзыв: `N. текст`.

Для КАЖДОГО файла прочитай все отзывы целиком (не выборку, не поиск по словам) и
запиши `tmp/reviews-out/<slug>.json`:

```json
{"praise":[{"theme":"Удобная парковка","ids":[3,17,42]}],
 "complaints":[{"theme":"Очереди в туалеты","ids":[5,88]}]}
```

- 5 самых частых тем, за которые ХВАЛЯТ, и 5 самых частых, на которые ЖАЛУЮТСЯ.
- Тема — конкретная, 2–6 слов по-русски, нейтрально, с заглавной буквы
  («Большой выбор магазинов», «Мало мест на фудкорте»). Без имён людей и
  сотрудников, без названий отдельных магазинов, без политики.
- `ids` — номера ВСЕХ отзывов, где тема явно упомянута (для жалобы — именно
  жалоба, для похвалы — именно похвала). Один отзыв может попасть в несколько тем.
- Темы не должны пересекаться по смыслу между собой.

теряло готовое; уже существующие файлы в `tmp/reviews-out/` пропускай. В конце —
список slug и число тем в каждом.
