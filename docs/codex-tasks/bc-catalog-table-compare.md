# Задание: табличный режим и сравнение бизнес-центров

Каталог БЦ Минска — маршрут `/minsk/bcminsk`. План: `BCMINSK_SEO_PLAN.md`, раздел
«Каталог — приоритет 2», два пункта:

1. Переключатель режима просмотра «карточки / таблица».
2. Сравнение БЦ: чекбокс «в сравнение» на карточке, до четырёх объектов,
   и экран сравнения.

Выбранное для сравнения должно переживать перезагрузку страницы и переход на карточку
и обратно — иначе сравнением невозможно пользоваться.

## Готово, когда

`npm run build:app` чистый; режим просмотра и набор для сравнения сохраняются между
перезагрузками; пятый объект в сравнение не добавляется, и пользователю понятно почему.
