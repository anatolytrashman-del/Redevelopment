## Журнал сессий и рабочие документы

Полный журнал сессий (261 запись, хронология по датам, новые — сверху) вынесен в
`docs/session-journal.md` — не дублировать работу, не переспрашивать то, что уже
решено, проверять журнал перед началом заметной новой порции работы. Не читать файл
целиком через Read — искать по дате/теме через `grep -n`/`sed -n`, читать только
нужный диапазон.

Дополнять журнал новыми записями **в `docs/session-journal.md`**, сверху (сразу
после заголовка и вводного абзаца), в том же формате `- **YYYY-MM-DD** — ...`;
`CLAUDE.md` под это больше не редактировать. Конфликт при мердже параллельных сессий
теперь тоже в этом файле, не в `CLAUDE.md`, — при мердже сохранять обе записи (см.
"Workflow при внесении изменений" выше).
