Служебный файл, не для сайта. Собирает весь негатив, который всплывал по ходу
ресёрча карточек застройщиков (`docs/bc-developer-cards.md`), в одном месте —
чтобы решить пакетом, а не по одному случаю. Пока ни один пункт ниже НЕ
опубликован и не должен появляться ни в карточке застройщика, ни где-либо ещё
на публичных страницах, пока владелец явно не решит иначе по каждому пункту.

## Правило (не меняется)

Владелец, 2026-09-20: явный негатив про любого застройщика — не решаю сам,
выношу на отдельное согласование. **Про Dana Holdings — вообще никогда
никакого негатива**, это жёсткое исключение поверх общего правила. Один
прецедент решения уже был: БЦ «Премьер» (ООО «Си-Трейдинг») — карточку
сделать, дефолт не упоминать; это разовое решение по конкретной компании, не
общий принцип «негатив можно скрывать по умолчанию».

Владелец, 2026-09-20 (этот файл): вместо согласования по одному случаю —

## Как читать эту таблицу дальше

Каждая строка — кандидат на отдельное решение владельца:
1. Публиковать карточку без негатива (как «Премьер») — или
2. Не публиковать вовсе, пока нет иной информации о компании (как сейчас
   `domashevsky`) — или
3. Что-то среднее (например, для `kolizey` — публиковать нейтральное описание
   компании-инвестора без упоминания истории самого здания, раз это не
   действие компании).

Новые находки негатива по ходу дальнейшего ресёрча — дописывать сюда же,
новой строкой, не решая самостоятельно, публиковать ли.
