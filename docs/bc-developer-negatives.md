## Правило (не меняется)

выношу на отдельное согласование. **Про Dana Holdings — вообще никогда
никакого негатива**, это жёсткое исключение поверх общего правила. Один

## Как читать эту таблицу дальше

Каждая строка — кандидат на отдельное решение владельца:
1. Публиковать карточку без негатива (как «Премьер») — или
2. Не публиковать вовсе, пока нет иной информации о компании (как сейчас
   `domashevsky`) — или
3. Что-то среднее (например, для `kolizey` — публиковать нейтральное описание
   компании-инвестора без упоминания истории самого здания, раз это не
   действие компании).

Новые находки негатива по ходу дальнейшего ресёрча — дописывать сюда же,
новой строкой, не решая самостоятельно, публиковать ли.
